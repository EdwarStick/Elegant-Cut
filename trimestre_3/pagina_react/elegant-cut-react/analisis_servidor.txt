2. ¿DÓNDE LO TIENES? (Ubicación de tu código actual)

   - Configuración: backend/package.json

-----------------------------------------------------------------------
3. ¿CÓMO LO MANEJA TU CÓDIGO ACTUAL? (Análisis Técnico)

   A. CREACIÓN DEL SERVIDOR
      - Tu código (server.js, línea 34-35):
        const http = require('http');
        const server = http.createServer(async (req, res) => { ... });
      
      - Lo que pide Express:
        const express = require('express');
        const app = express();

   B. MANEJO DE RUTAS (URLs like /login)
      - Tu código (Lo haces manual con IFs):
        if (req.url === '/auth/login' && req.method === 'POST') { ... }
      
      - Lo que pide Express:
        app.post('/auth/login', (req, res) => { ... });

   C. LECTURA DE DATOS (El "body" de la petición)
      - Tu código (Manual y complejo):
        let body = '';
        req.on('data', chunk => body += chunk.toString()); // Recibes pedacitos
        req.on('end', () => { JSON.parse(body) ... });    // Los unes al final
      
      - Lo que pide Express (Automático):
        app.use(express.json()); // Una sola línea hace todo eso por ti.
